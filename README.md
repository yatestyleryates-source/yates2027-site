# yates2027.com

Wedding website for Isaiah Tyrese Flippin & Tyler Allen Yates. February 14, 2027, aboard *Symphony of the Seas*, sailing from Galveston, Texas.

A single static page (`index.html`) served by GitHub Pages.

- **Links** (RSVP form, registry, cruise booking) live in the `LINKS` object near the bottom of `index.html`.
- `share-card.png` is the preview image shown when the link is texted or posted.
